# Stroke / déficit neurológico agudo

## Immediate priorities
Tempo de início; glicemia se informada; via aérea se rebaixamento. Não infundir hipótese de AVC como fato.

## Dangerous diagnoses to consider
AVC isquêmico; hemorragia intracraniana; hipoglicemia; convulsão com déficit; dissecção; meningite/encefalite se febre.

## High-value history
Última vez visto normal; uso de anticoagulante; trauma; convulsão; cefaleia súbita; gravidez.

## Examination priorities
Assimetría facial, fala, força, campo visual — só o que foi observado. NIHSS completo só se examinado.

## Initial tests commonly considered
Glicemia capilar, TC/angio conforme protocolo local, coagulação se anticoagulante.

## Important treatment considerations
Janela de trombólise/trombectomia é decisão especializada. Não documentar trombólise como feita.

## Red flags
Déficit súbito; cefaleia em trovoada; rebaixamento; uso de varfarina.
