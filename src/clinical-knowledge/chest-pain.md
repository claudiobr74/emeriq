# Chest Pain

## Immediate priorities
Estabilidade (via aérea, respiração, circulação). Dor torácica + hipotensão, síncope, dispneia, sudorese ou irradiação dorsal exige reavaliação imediata. Não confirmar SCA só pela queixa.

## Dangerous diagnoses to consider
Síndrome coronariana aguda; dissecção aórtica; TEP; pneumotórax hipertensivo; ruptura esofágica. Manter diferenciais graves visíveis até haver dados para reclassificar.

## High-value history
Início, caráter, irradiação, esforço, sudorese, náusea, síncope, déficit neurológico, uso de cocaína, anticoagulante, cirurgia recente, gravidez.

## Examination priorities
PA nos dois braços se dissecção for plausível; sinais de choque; assimetria de pulsos; ausculta pulmonar e cardíaca somente se descritas.

## Initial tests commonly considered
ECG, troponina, RX/US se indicado, gasometria/D-dímero só com probabilidade intermediária de TEP. Não registrar exame como realizado se só foi sugerido.

## Important treatment considerations
AAS, nitrato, anticoagulação e reperfusão são decisões médicas. Linguagem: considerar, avaliar. Hipotensão contraindica nitrato.

## Red flags
Dor súbita em rasgo para o dorso; PA assimétrica; síncope; déficit focal; instabilidade.
